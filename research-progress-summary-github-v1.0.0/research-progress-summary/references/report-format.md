# Report Format

このファイルは研究進捗報告の構成部品を定める。

## 完全版の順序

### 1. 今回の要約

3～5文を目安に、対象期間、主要な実施内容、確認された結果、現在の課題をまとめる。新しい事実を作らない。文末に根拠IDを付ける。

例: `条件Aと条件Bを比較した。[ACT-01][COND-02]`

### 2. 目標・背景

入力に明記された目標または背景だけを書く。ない場合は「情報なし」。

### 3. 実施したこと

作業、方法、条件を箇条書きにする。作業と結果を同じ項目で混同しない。

### 4. 得られた結果

測定値、観察結果、成果物を記載する。成功、失敗、未判定を区別する。比較は入力に明記された範囲だけで行う。

### 5. 考察

入力者が記した解釈・仮説だけを記載する。AIが追加する解釈は原則禁止。依頼された場合も「追加考察」と明示し、事実と分離する。

### 6. 課題・未解決事項

未確認事項、問題、判断待ちをまとめる。推測で解決済みにしない。

### 7. 次に行うこと

入力にある予定を、可能なら次の形にする。

- 優先度: 入力値。なければ要確認
- 作業: 実施すること
- 完了条件: 入力に明記されている場合のみ
- 根拠: 台帳ID

### 8. 前回からの変更点

前回報告がある場合のみ作成する。

- 新規
- 変更
- 継続
- 完了
- 未完了

### 9. 根拠台帳

折りたたまず全文を載せる。形式:

```text
[RESULT-01] 種別: 客観的結果
原文: 「...」
出典: source.md 12行目
使用先: 得られた結果
```

## 短縮版

`brief` では「要約」「結果」「課題」「次の行動」を基本とする。ただし、根拠台帳は省略せず末尾に付ける。
