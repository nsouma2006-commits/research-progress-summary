# Evidence Rules

## 根拠の階層

1. 入力に直接書かれた事実
2. 入力に直接書かれた解釈・仮説
3. 入力に直接書かれた予定
4. 不明・要確認

上位と下位を混同しない。

## 禁止事項

- 入力にない事実、数値、日付、担当者、原因、判断を足す
- 単位を無断で換算する
- 小数の丸めや割合計算を無断で行う
- 相関を因果として書く
- 未確認の仮説を結論として書く
- 予定を実施済みとして書く
- 進展を誇張する
- 引用文を意味が変わるように短縮する

## 許可される編集

- 原文の意味を保った並べ替え
- 見出しと箇条書きによる構造化
- 重複する記録の統合。ただし台帳IDはすべて残す
- 表記ゆれの指摘。本文を勝手に統一せず要確認とする

## 最終チェック

- [ ] 入力の主要情報が台帳にすべてある
- [ ] 本文の主要記述に台帳IDがある
- [ ] 事実と考察を分離した
- [ ] 仮説を仮説として表示した
- [ ] 数値と単位が原文と一致する
- [ ] 条件と固有名詞が原文と一致する
- [ ] 前回との差分を推測していない
- [ ] 優先度や完了条件を捏造していない
- [ ] 不明事項を要確認とした
- [ ] 個人情報と未公開情報の扱いを確認した
