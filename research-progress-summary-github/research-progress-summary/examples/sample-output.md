# 研究進捗まとめ

## 1. 今回の要約

前処理方法AとBを同一の訓練データで比較し、各条件を3回実行した。平均正解率は方法Aが82.1%、方法Bが86.4%であり、今回の条件では方法Bが4.3ポイント高かった。一方、方法BではクラスCの再現率が低く、原因確認が次の課題である。

## 2. 実施したこと

- 前処理方法AとBを比較した。
- 同じ訓練データを用い、各条件を3回実行した。
- クラス別評価を追加した。

## 3. 得られた結果

- 方法Aの平均正解率: 82.1%
- 方法Bの平均正解率: 86.4%
- 方法Bは方法Aより4.3ポイント高かった。
- 方法BではクラスCの再現率が低かった。

## 4. 考察

今回の条件では、方法Bの平均正解率が方法Aを上回った。ただし、クラスCの再現率が低いため、全体の正解率だけで優劣を確定することはできない。クラスCのデータ数不足が原因である可能性はあるが、現時点では未確認である。

## 5. 課題・問題点

- クラスCの再現率低下の原因が未確認である。
- クラスごとのデータ数と誤分類傾向を追加確認する必要がある。

## 6. 次に行うこと

1. **優先度: 高** 混同行列を確認し、クラスCがどのクラスへ誤分類されているかを特定する。
2. **優先度: 高** クラスCを含む各クラスのデータ数を集計する。
3. **優先度: 中** データ数と再現率の関係を確認し、追加実験の条件を決める。

## 7. 前回からの変更点

- 前処理方法AとBの比較を実施した。
- クラス別評価を追加した。
- 新たな課題として、クラスCの再現率低下を確認した。
